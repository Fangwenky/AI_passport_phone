接入新模块

一个稳定 ID 串起统一清单、电脑设置页和手机显示页。桥接程序负责保存配置并同步给所有端。

1

注册清单

在 mac/modules.js 添加名称、说明、分类、图标、设置类型与能力标签。

2

实现设置

Mac 和 Windows 按 settings 字段打开对应设置页，统一写入 /modules。

3

实现手机页

Android 用同一个模块 ID 注册显示页面，并从 snapshot 读取配置。

完整字段、数据流和检查清单见仓库 docs/MODULES.md。
